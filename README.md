## 🛠 Project Structure & Features

The project is split across separate HTML pages linked by a unified navigation header:

### 1. Part 1: Flexbox (`index.html`)
* **Task 0 (Navigation Bar):** Built with Flexbox (`justify-content: space-between`, `align-items: center`) containing a logo and interactive navigation links.
* **Task 1 (Card Row):** A row of 3 cards with equal heights (`align-items: stretch`), consistent gap spacing, and smooth hover transition effects (`transform: translateY` and `box-shadow`).

### 2. Part 2: Grid System (`grid.html`)
* **Task 2 (Page Layout):** Page layout structured using `display: grid` and `grid-template-areas` comprising Header, Sidebar, Main content, and Footer.
* **Task 3 (Image Gallery):** A 3x3 responsive grid gallery with 9 items, CSS gap spacing, and a text overlay effect (`.overlay` with `opacity: 1` transition) on hover.

### 3. Part 3: Combining Flexbox & Grid (`portfolio.html`)
* **Task 4 (Portfolio Page):** A complex page structure combining both techniques:
  * Flexbox for header navigation.
  * CSS Grid for main layout distribution (Projects area on the left, Sidebar on the right).
  * Flexbox inside individual project cards for content and button alignment.
  * Full-width footer at the bottom.
